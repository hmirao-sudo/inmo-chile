# Inmo Chile

Sitio y gestión inmobiliaria en WordPress para una corredora chilena (ventas y arriendos).

- `inmo-chile/` — plugin: propiedades, captación, CRM, permisos y formularios.
- `inmo-vitrina/` — tema: vitrina pública.
- `pruebas/` — pruebas de aceptación (Playwright) y utilidades de entorno local.
- `docs/LEEME-ENTREGA-1.md` — instalación, mapa de pantallas, modelo de datos, roles y pendientes.
- `docs/ENTREGA-2.md` — oportunidades, ofertas, plantillas versionadas, PDF y expediente.
- `docs/ADMINISTRACION-ARRIENDOS.md` — cobranza mensual, reajustes y liquidaciones a propietarios.

Estado: Entregas 1 y 2 y administración de arriendos completas. Pruebas en WordPress 7.1.5 es_CL: 33/33, 23/23 y 21/21 (`pruebas/ejecutar.sh`).
En espera: portales inmobiliarios y firma electrónica. Siguientes: portal privado del dueño y valorización automática.
